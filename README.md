# Tom & Jerry: Великая погоня

Однофайловая 2D-игра на HTML Canvas. Выбери Тома и поймай Джерри или играй за Джерри, собери три сыра и доставь их в норку. Дом показан сбоку в разрезе, в нём два этажа, лестница, мебель и предметы для удара.

Персонажи нарисованы и анимированы кодом. У каждого есть три случайные idle-анимации, которые включаются после пяти секунд бездействия. Музыка и звуковые эффекты синтезируются в браузере через Web Audio.

## Управление

- ← / → или A / D — ходить.
- ↑ / ↓ у лестницы — перейти между этажами.
- Пробел — прыгнуть; с предметом в руках — ударить.
- E — подобрать или бросить предмет.
- P — пауза.

На телефоне доступны сенсорные кнопки.
